This is the test project. It's created to learn and practice e2e testing using Cypress.
Open [https://docs.cypress.io/app/get-started/why-cypress] to read the docs.

## Getting Started

First, install dependencies:

```bash
yarn install
```

Second, run the development server:

```bash
yarn dev
```

## Testing

Cypress testing library for e2e tests.

```bash
yarn cypress:open
```
